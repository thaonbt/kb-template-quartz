# Welcome to My Digital Garden 🌱

> **Thank you, [Quartz](https://quartz.jzhao.xyz/)!**
> Quartz cho phép xây dựng trang web như một Digital Garden mượt mà và trực quan giống như trải nghiệm trên Obsidian. Template này được tối ưu và xây dựng dựa trên nền tảng **Quartz v5**.

---

## 🚀 Giới thiệu về Template này

Đây là **Template Digital Garden** cá nhân được cấu hình sẵn dựa trên **Quartz v5**, giúp bạn dễ dàng xuất bản các ghi chú Markdown từ Obsidian (hoặc bất kỳ trình soạn thảo Markdown nào) thành một trang web tĩnh hiện đại, tốc độ cao và hoàn toàn miễn phí.

### ✨ Tính năng nổi bật đã tích hợp:

* 🔗 **Hỗ trợ Wikilinks & Obsidian Syntax**: Đọc mượt mà các cú pháp `[[Link]]`, callout, highlight và nhúng file.
* 🕸️ **Interactive Graph View**: Trực quan hóa mạng lưới liên kết giữa các bài viết.
* 🔍 **Full-text Search**: Tìm kiếm nhanh chóng toàn bộ nội dung trên trang.
* 🌙 **Dark/Light Mode**: Tự động chuyển đổi giao diện sáng/tối theo hệ thống hoặc tùy chọn của người đọc.
* ⚡ **Tốc độ cực nhanh**: Tối ưu hóa hiệu năng tối đa nhờ công nghệ SSG (Static Site Generator) mới nhất của Quartz v5.

---

## 🛠️ Hướng dẫn bắt đầu nhanh (Quick Start)

Nếu bạn muốn clone repository này về để tự dựng trang web cho riêng mình:

1. **Clone Repo này:**
   
   ```bash
   git clone <URL_REPO_CUAR_BAN>
   cd <TEN_THUMUC_REPO>
   ```
2. **Cài đặt dependencies:**
   
   ```bash
   npm install
   ```
3. **Chạy thử ở local (Local Development):**
   
   ```bash
   npx quartz build --serve
   ```
   
   Sau đó mở trình duyệt tại `http://localhost:8080`.
4. **Thêm bài viết mới:**
   Chỉ cần tạo file `.md` mới trong thư mục `content/` và bắt đầu viết!

---

## 📂 Cấu trúc thư mục chính

```text
├── content/              # Bỏ tất cả ghi chú / bài viết Markdown vào đây
│   ├── index.md          # Trang chủ (chính là trang này)
│   └── ...
├── quartz.config.yaml    # Cấu hình chính của Quartz v5 (Theme, Plugins)
└── quartz.layout.ts      # Tùy chỉnh bố cục giao diện (Header, Sidebar, Footer)
```
